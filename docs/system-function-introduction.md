 # 高铁智能设计系统功能介绍文档

## 1. 系统定位

本系统面向高速动车/高铁列车涂装设计流程，将设计师的文化主题解读、纹样检索、纹样转化画布、车身布局、色彩配置、涂装案例和最终效果生成串联成一个连续的 AI 辅助工作流。

系统并不是单一的“输入一句话生成图片”工具，而是把设计过程拆成多个可控阶段：先帮助用户澄清并发散文化主题，再从知识图谱中检索可用纹样素材，随后在纹样转化画布中组织和转化提示图，再选择车身布局区域和色彩方案，最后将所有阶段的结构化信息与参考图一起提交给生图模型，生成可用于方案讨论和汇报的列车侧视涂装效果图。

## 2. 项目、用户与保存机制

### 2.1 用户登录

系统支持用户登录与退出。登录后，用户的项目、会话记录、选中的素材、画布内容和最终方案会绑定到当前用户工作区，避免不同用户之间的数据混淆。

### 2.2 项目管理

顶部项目栏提供项目级操作，包括：

- 新建项目：创建一个全新的设计项目，用于从零开始组织需求、素材、布局、色彩和最终方案。
- 切换项目：在已有项目之间切换，系统会加载该项目对应的完整工作状态。
- 重命名项目：修改当前项目名称，便于按客户、线路、主题或版本管理。
- 删除项目：删除当前不再需要的项目。

每个项目都拥有独立的数据快照。文化主题解读、纹样检索、纹样转化画布、车身布局、色彩方案、涂装案例和效果生成结果都会按项目隔离保存。

### 2.3 自动保存与手动保存

系统具备自动保存机制。用户在各页面中进行的关键操作，例如确认文化主题、选择纹样、编辑画布、截取提示图、保存车身布局方案、调整色彩、选择涂装案例和生成最终效果，都会进入当前项目的工作快照。

顶部的“保存记录”按钮用于立即触发一次手动保存，适合在演示前、完成阶段性工作后或准备刷新页面前主动确认当前状态。理想使用方式是：日常操作依赖自动保存，关键节点点击“保存记录”作为保险。

## 3. 页面功能说明

### 3.1 文化主题解读页面

文化主题解读页面是系统的设计起点，目标是把用户输入的文化主题或涂装方向转化为可继续检索和生成的设计意象标签。

用户可以在对话框中输入想要发散的文化主题，例如“希望做一款融合中国文化、京张精神和奥运元素的高铁涂装”。系统会通过设定好的“涂装设计策略专家”提示词，将用户输入拆解为设计主题、文化方向和候选意象。

AI 的处理逻辑包括：

- 分析用户输入中包含的地域、文化、品牌、历史、事件或情绪线索。
- 从主题中发散出更明确的设计方向，例如从“京张铁路”延展到“边塞文化”，从“冬奥”延展到“冰雪运动”。
- 将主题进一步下钻为具体基础意象，例如龙、凤、长城、雪花、滑冰、燕山山脉等。
- 严格避免直接输出设计手法，例如“渐变”“剪影拼接”“速度感线条”等，因为这些属于后续视觉设计阶段。

AI 回复中会按照系统约定生成 `[TAG: 主题-意象]` 或 `[TAG: 意象]` 格式的标签。前端会识别这些标签并转化为可点击的意象 tag。用户可以选择或取消选择生成的 tag，并将确认后的 tag 作为后续纹样检索的输入。

本页面输出到下一阶段的核心数据是：用户确认的文化主题与设计意象标签。

### 3.2 纹样检索页面

纹样检索页面负责把文化主题解读阶段确认的意象 tag 转化为图谱查询条件，并从本地知识图谱中检索相关纹样、图案和文化素材。

进入页面后，系统会读取文化主题解读页面已确认的意象 tag，并自动触发一次检索。用户也可以在输入框中手动补充关键词，例如“龙纹”“雪花”“唐代纹样”等。

AI 与图谱的处理逻辑包括：

- 通过设定的“传统文化、纹样学与知识图谱查询构建”提示词，将自然语言输入解析为结构化过滤条件。
- 识别用户输入中的纹样、朝代、材质、情绪、工艺等信息。
- 将这些信息映射到 Neo4j 图谱中的实体类型，例如 Pattern、Motif、Dynasty、Material、Carrier、Layout。
- 根据解析结果查询本地知识图谱，返回匹配的纹样素材。

页面中间区域展示检索结果卡片，每张卡片包含图像、标题、年代、编号等信息。用户可以点击选择感兴趣的纹样素材，右侧会形成“已选纹样清单”。

本页面输出到下一阶段的核心数据是：用户选中的纹样素材及其标题、年代、编号、图片地址和相关描述。

### 3.3 纹样转化画布页面

纹样转化画布页面是系统中的自由创作与提示图组织区域。它让用户把已选纹样、生成素材、列车参考图和局部构图以可视化方式摆放出来，形成最终生图模型可以参考的提示图。

左侧显示用户在纹样检索中选中的纹样素材，用户可以将这些素材拖入画布。画布本身是白色背景的工作区，支持常见的编辑操作：

- 选择图层。
- 移动图片。
- 缩放图片。
- 旋转图片。
- 裁剪图片。
- 复制图片。
- 删除图片。
- 上传本地图片。
- 使用画笔绘制。
- 使用橡皮擦擦除。
- 调整画布缩放比例。

用户可以按住 Shift 多选多个图层。多选后的图片可以作为同一次 AI 转化的提示图，使模型同时参考多张纹样或构图素材。

页面底部提供 AI 转化输入框。用户可以输入局部转化需求，例如“将这个龙纹转化为红色”“生成雪花纹样”“让纹样更适合车身侧面装饰”。系统会将选中的图层作为参考图提交给生图模型，生成结果会以新的图片图层返回到画布中。

右侧为“截取素材”面板。用户可以使用截取工具在画布中框选局部画面，保存为提示图。截取后的图片会进入右侧列表，也可以重新添加回画布。效果生成阶段默认主要读取这些“画布截取”作为提示图，而不是把所有纹样检索图片都直接提交给最终模型。

本页面输出到下一阶段的核心数据是：画布图层、AI 转化素材、画布截取图片，以及用户希望最终模型参考的局部效果图。

### 3.4 车身布局页面

车身布局页面用于定义列车涂装中哪些车体区域需要作为独立设计区域。它解决的是“图案和色彩应该放在哪些车体部位”的问题。

页面按照列车车体结构将车身布局区域分为多个类别，包括：

- 车窗带，例如 A1、A2、A3。
- 车门，例如 C1。
- 车顶侧，例如 D1、D2。
- 车底侧，例如 E1。
- 下车底区，例如 F1、F2、F3。
- 车头侧，例如 G1-G4。
- 腰线，例如 B1-B4。

用户可以在每个类别中选择一个布局元素。系统会把用户选择的组件整理成车身布局方案，例如“车窗带：A2，车门：C1，车顶侧：D1”。如果某个区域不选择，则默认该区域不作为独立施色或重点装饰区域。

右侧“车身布局清单”会展示当前已选择的区域，并支持保存车身布局方案、重命名车身布局方案和删除车身布局方案。保存后的车身布局方案会在后续色彩配置和效果生成中继续使用。

本页面输出到下一阶段的核心数据是：车身布局方案名称、各车体区域对应的布局元素编号，以及布局元素图片参考。

### 3.5 色彩配置页面

色彩配置页面用于基于已保存的车身布局方案，为不同车体区域配置色彩。它解决的是“每个布局区域应该是什么色彩”的问题。

页面会读取用户在车身布局页面保存的布局方案，并根据布局方案自动生成可配置的色彩区域。系统默认包含“车身主色”，同时会将用户选中的布局类别转化为独立的色彩区域，例如车窗带、车门、车顶侧、车底侧等。

用户可以进行以下操作：

- 选择当前要配置的车身布局方案。
- 为每个车体区域设置色彩。
- 使用图片取色功能，从上传图片中提取配色参考。
- 保存色彩方案，形成可复用的“色彩方案 1”“色彩方案 2”等。
- 在已保存色彩方案之间切换。

系统不仅保存色彩值，也会保存色彩所属区域、区域名称、布局元素图片和区域描述。这样在最终生成阶段，模型不仅能看到“红色”，也能知道这个红色应该应用在“车窗带”还是其他区域。

本页面输出到下一阶段的核心数据是：色彩方案名称、每个车体区域的色彩值、区域说明、布局元素映射和取色参考。

### 3.6 涂装案例页面

涂装案例页面用于检索列车涂装案例，帮助用户为最终效果提供更接近行业语境的参考。它解决的是“参考什么成熟案例，以及参考案例中的哪些部分”的问题。

用户可以在对话框中输入案例需求，例如“复兴号”“红色车窗带”“CR 标识位置”“现代高铁侧视涂装”等。系统会通过涂装案例服务从案例库或图谱中查找相关列车涂装案例，并在对话区返回案例卡片。

用户可以选择一个或多个案例加入右侧参考清单。每个案例支持用户填写补充说明，例如：

- 参考 CR 标识在车窗带上的位置。
- 参考车头侧面红色线条的比例。
- 参考案例中的腰线位置，不复刻车型文字。

这些说明非常重要，因为它们会被作为最终生图提示词的一部分，让模型理解用户不是要复制整张案例图，而是参考案例中的位置、比例、标识或构图关系。

本页面输出到下一阶段的核心数据是：选中的涂装案例图片、案例标题、案例描述，以及用户对每个案例填写的参考说明。

### 3.7 效果生成页面

效果生成页面是系统的汇总与最终出图页面。它会将前面各阶段产生的结构化信息和参考图整理成完整设计包，再提交给生图模型生成最终列车涂装效果图。

左侧“设计输入”区域展示当前效果生成所需的输入完整度，包括：

- 车身布局：来自车身布局页面保存的布局方案。
- 涂装案例：来自涂装案例页面选中的案例和用户说明。
- 纹样素材：来自纹样检索页面选中的纹样素材。
- 色彩方案：来自色彩配置页面保存或当前编辑中的色彩方案。
- 提示图：来自纹样转化画布阶段截取保存的画布局部效果图。

系统会把这些输入组装成最终设计包。设计包中既包括文本信息，也包括参考图片：

- 文化主题标签会整理为设计目标。
- 车身布局方案会整理为“车窗带：A2”等区域配置，并生成布局参考图。
- 色彩方案会整理为每个区域的色彩值和说明，并生成色卡或着色布局参考图。
- 纹样素材会整理为纹样名称、年代、描述和图片参考。
- 涂装案例会整理为案例标题、案例说明、用户填写的参考位置说明和案例图片。
- 纹样转化画布截取图会作为默认提示图参与最终生图。

中间区域用于预览当前生成结果。底部输入框用于补充最终生成要求或微调指令。当当前还没有生成图时，按钮执行“首次生成”；当已有当前效果且左侧输入没有变化时，用户输入会被视为针对上一版效果的微调；当左侧输入发生变化时，再次点击会基于新的设计包重新生成，而不是只对旧图微调。

页面还提供“清除当前效果”和“保存方案”能力：

- 清除当前效果：放弃当前预览图，回到基于左侧输入重新生成的状态。
- 保存方案：将当前生成结果归档为一个方案版本，进入右侧“已归档方案”列表。

右侧“已归档方案”用于保存历史生成版本。用户可以查看不同版本的图片、生成时间和说明，并删除不需要的归档方案。

本页面输出的核心结果是：最终列车涂装效果图、对应生成提示词、设计依据说明和可归档的方案版本。

## 4. 跨页面数据流

系统的核心价值在于各页面之间不是割裂的，而是形成了连续的数据链路：

1. 文化主题解读页面将用户输入转化为文化主题与设计意象 tag。
2. 纹样检索页面将 tag 和关键词转化为图谱查询条件，并返回可选纹样素材。
3. 纹样转化画布页面允许用户把纹样、列车图、AI 转化图和局部构图组织成提示图。
4. 车身布局页面定义车体哪些区域作为重点设计区域。
5. 色彩配置页面为这些区域配置色彩，并生成区域化色彩方案。
6. 涂装案例页面补充成熟列车案例，并允许用户说明具体参考点。
7. 效果生成页面将以上所有信息整合为设计包，提交给生图模型生成最终效果。

因此，最终生成图并不是只依赖用户最后输入的一句话，而是综合使用了前面所有阶段积累的设计信息。

## 5. 系统能力总结

从功能层面看，系统具备以下能力：

- 文化主题解读能力：将模糊的设计诉求转化为可操作的文化主题与设计意象。
- 知识检索能力：基于 Neo4j 图谱检索传统纹样、朝代、材质和图案素材。
- 设计约束能力：通过车身布局和色彩区域，让 AI 生图受到车体结构约束。
- 视觉组织能力：通过纹样转化画布让设计师手动组织构图、素材和提示图。
- 案例迁移能力：通过涂装案例和用户备注，将成熟设计案例中的位置、比例和标识关系迁移到新方案中。
- 多模态生成能力：将文本、布局图、色彩图、案例图和画布截取图共同提交给生图模型。
- 项目沉淀能力：通过用户登录、项目管理和自动保存，将每个项目的完整工作过程沉淀下来。

从设计流程层面看，系统强调“AI 参与设计过程”，而不是让 AI 直接替代设计师。设计师仍然负责选择主题、筛选素材、确定布局、配置色彩、组织提示图和判断最终效果；AI 则负责在每个阶段提供检索、推理、生成和转译能力。
