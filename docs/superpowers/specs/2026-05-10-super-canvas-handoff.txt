一、这次完成了什么

本次新增了“超级画布”页面和配套后端生图接口。整体目标是让用户从“意象图片检索”模块选择纹样图片，拖入一个可编辑画布；用户也可以上传高铁白膜等底图，在画布上移动、缩放、涂鸦、框选保存素材，并通过底部提示词调用即梦图片生成 4.0，生成透明底 PNG 后回填到画布。

主要功能包括：
1. 顶部导航新增“超级画布”入口。
2. 左侧可折叠/可调整宽度面板展示已选意象图片，并支持拖拽到画布。
3. 中间画布支持：
   - 拖入纹样图片；
   - 上传本地图片；
   - 选择、移动、滚轮缩放图片图层；
   - 画笔涂鸦和批注；
   - 框选区域并导出为 PNG；
   - 底部输入提示词调用后端生图。
4. 右侧可折叠/可调整宽度面板展示框选得到的图片素材，并支持再次拖回画布。
5. 后端新增 /super-canvas/generate 接口：
   - 使用 Volcengine AK/SK 签名；
   - 调用即梦图片生成 4.0 模型；
   - 处理 URL 或 base64 返回图；
   - 将图片后处理为透明底 PNG；
   - 保存到 generated/super-canvas；
   - 返回相对图片路径给前端。
6. 后端增强了参考图安全处理：
   - data URL、本地 backend URL、站内 URL 会先由后端下载/保存/重新发布，再传给即梦；
   - 任意公网 http/https 图片可直接透传；
   - localhost、内网、链路本地、IPv6 私网、IPv4-mapped IPv6 私网等地址会被拒绝，避免把后端做成带凭证的内网代理；
   - 如果需要把上传图/框选图/本地图片作为即梦参考图，必须配置公网可访问的 SUPER_CANVAS_PUBLIC_BASE_URL。

三、环境变量

后端必须配置：
- JIMENG_ACCESS_KEY_ID
- JIMENG_SECRET_ACCESS_KEY

不要把密钥写入前端，也不要提交到 git。之前对话里出现过密钥，正式使用前建议在火山/即梦侧轮换一次。

可选但很重要：
- SUPER_CANVAS_PUBLIC_BASE_URL

说明：
- 如果用户只做纯文本生图，不传参考图，可以不配置 SUPER_CANVAS_PUBLIC_BASE_URL。
- 如果用户要把上传图、框选图、本地站内图作为参考图给即梦使用，必须配置为公网可访问的后端地址，例如 https://your-public-backend.example.com。
- 不能配置 localhost、127.0.0.1、内网地址、*.localhost、localhost. 等地址。后端会拒绝这些地址。
- 本地联调可用 ngrok、Cloudflare Tunnel、内网穿透等工具把后端 3000 暴露出去，然后把 SUPER_CANVAS_PUBLIC_BASE_URL 指向该公网地址。

前端可选配置：
- VITE_API_BASE_URL

默认值是 http://localhost:3000。部署环境应设置为真实后端地址。

11. 底部输入框为空时点击 AI 生成，不应调用有效生成。

    - 选中图片图层时，会把该图作为参考图；
    - 如参考图是本地/上传/框选图，后端必须配置公网 SUPER_CANVAS_PUBLIC_BASE_URL，否则会返回清晰错误。
13. 后端返回图片后，画布中应新增“AI 生成纹样”图层。

六、已做的安全和稳定性处理

1. 前端不保存、不暴露即梦密钥。
2. 后端只从环境变量读取 JIMENG_ACCESS_KEY_ID 和 JIMENG_SECRET_ACCESS_KEY。
3. request body 限制已放大到 30 MB，以支持 data URL 参考图。
4. 参考图 data URL 只支持 png、jpg/jpeg、webp。
5. 参考图和生成图下载都有字节上限，默认 20 MB。
6. 图片下载有超时控制。
7. 生成文件名使用 basename，避免路径穿越。
8. 私网/localhost/特殊 localhost alias/IPv4-mapped IPv6 私网等参考图 URL 会被拒绝或在站内场景下重新发布，不会原样发给即梦。
9. 本地/上传/框选参考图需要公网基址，否则后端会提前拒绝，而不是把 localhost 地址传给云端。
10. 画布侧面板 resize 已处理 pointerup、pointercancel、重复 resize 和组件卸载清理。
11. 上传文件限制为 image/* 且最大 20 MB。
12. 拖拽数据有运行时 shape 校验。

七、当前已知注意点

1. 生产环境 CORS 仍偏本地开发配置，当前 main.ts 主要允许本地 Vite 源。正式部署前建议改为环境变量驱动。
2. 选中图层目前只显示蓝色 outline，不会自动提升到最高层；重叠图层场景下后创建的图层可能盖住选中图层。
3. 前端长耗时异步任务没有完整 AbortController 取消机制；切换页面后，极端情况下回调仍可能完成。当前风险较低，但后续可加 mounted guard 或 abort。
4. 即梦参考图能力依赖公网可访问地址。纯本地 localhost 环境可以验证 UI 和接口校验，但不能让云端访问本地图片。
5. 外层仓库当前存在大量原本就未跟踪的应用文件；本次提交只纳入了与超级画布相关的新增/修改文件。gaotie-server 是独立 git 仓库。
