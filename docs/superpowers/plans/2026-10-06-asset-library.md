# 资产沉淀实施计划

目标：当前账号跨项目查看收藏纹样和涂装方案，可筛选项目；画布收藏、方案保存均落 PostgreSQL。

设计：新增 assets 表和登录鉴权的 AssetsModule，按 user_id 查询。原方案归档 HTTP 接口接入资产库，停止使用共享内存。收藏图片存储独立副本，方案保存生成时的设计包和项目快照。没有归属信息的旧内存归档不自动分配给当前用户。前端新建资产页（筛选、搜索、两类卡片、详情），新增画布收藏控件和方案保存表单。

- [x] 后端测试：用户隔离、项目归属、重复收藏幂等、无效图片、持久保存、逻辑删除。
- [x] 数据库迁移与资产接口；已有方案归档接口统一持久化。
- [x] 画布收藏当前转化图片，保留裁剪、翻转和透明背景；支持截图收藏。
- [x] 生成时记录项目及设计包；保存表单补充名称、主题、意象，不能把生成后修改的输入混入旧方案。
- [x] 资产页展示、搜索和项目筛选；查看方案完整记录和图片。
- [x] 前后端测试、构建、双账号接口验收、浏览器验证收藏与保存。

验收：账号 A 的资产不能被账号 B 读取或删除；重启后资产保留；空列表、加载失败、重复点击均可恢复；保存方案后改动当前工作区不改变资产详情；布局及纹样参考可预览；不调用付费生图以验证收藏。


验证记录：前端 13 个文件 74 项相关测试通过；后端 47 个测试套件 422 项测试通过。前后端构建通过；修改范围前端 lint 通过。真实双账号验证收藏与方案的保存、幂等、鉴权、隔离、逻辑删除/重新收藏；后端重启后验证两类资产仍在数据库。临时验收账号已清理。浏览器验证当前选中转换图收藏、列表、详情，已验证保存方案表单自动带入原始意象。

使用：在画布选中 AI 转化图片点击工具栏星标；截图卡片也提供星标。效果生成点击保存方案，填写名称、主题和意象。资产沉淀跨项目按类型展示，支持项目筛选与文字搜索，详情可查看原始布局视图、实际参考、配色、案例和提示词。

限制：旧共享内存归档不含账号归属，且重启后即失效，不自动迁移为任一用户资产。新保存的内容持久化。测试未调用付费生图。


独立审查：发现归档 DTO 仍返回原始文件地址的问题，已修正为数据库图片地址。归档重存与继续生成读取私有图片时按登录用户鉴权。补充图片持久 URL、远程同路径拒绝、跨账号图片读取、迭代鉴权测试；最后 14 项后端定向测试通过，构建通过。审查复核无剩余 P1/P2。

## 资产来源与知识图谱扩展（2026-10-06）

- 资产页增加可见删除入口、独立删除确认、白底预览、可键盘操作的项目筛选、知识图谱页签。
- `PatternProvenance` 保存生成的原提示词、优化提示词、实际输入图片、所有原始知识纹样 ID 和输出来源。多轮生成继承根纹样；画布截图记录区域相交图层来源。
- `asset_reference_images` 按账号及内容哈希保存图片副本。收藏原图及方案采用参考不依赖临时画布或收藏条目的存续。读取要求账号权限；继续调整将原参考及提示词载回当前画布，不自动生成。
- PostgreSQL 为权威记录；Neo4j 为可重建投影。保存/删除后异步同步，启动时补偿，查询前自愈。Neo4j 不可用不影响资产保存，图谱显示明确错误与重试入口。
- Neo4j 节点统一受 `DesignAssetNode.ownerId` 隔离，并按项目、原始纹样、转化纹样、方案、主题、意象、布局、最终图片设置专用标签。来源链按原始知识纹样 ID 归一，不把仅加入选材列表的未采用纹样算入方案。
- `/assets/graph?query=&projectId=&hops=3` 返回节点、边、资产与解释路径；1–6 跳、最多 500 节点/2,000 边。原始纹样查询的结果沿正向来源链匹配，排除同项目但未采用的方案。
- 历史示范复用原有透明龙纹与已保存方案，保留修改前本地备份。原始纹样 P00528 有项目图层证据；历史方案参考选择缺失，按此次用户说明补录，详情中标明；不宣称恢复了逐次生图审计。

验证涵盖跨账号读取、图片持久化、删除/重收藏、Neo4j 多跳与无关方案排除、来源继承、恢复图片期间项目切换、UI 删除取消/重试与筛选。端到端脚本使用可清理的临时账号，不发起图像生成。
