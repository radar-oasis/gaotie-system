# Codex 本地生图与多图设计包修正

用户已批准本地Codex接入，并明确本轮优先纠正最终效果多图+文字设计包。双纹样风格迁移角色UI暂不扩展。

1. 独立Codex适配器：沿用已验证stdio协议；限流、超时、错误、图片校验；读取本系统图片或dataURL，不转交任意文件路径或凭证。默认不改线上配置。
2. 最终设计包：按实际附件构建带角色的清单；保留画布构图、全部选中布局、案例及对应说明、色彩；不静默截断，附件缺失则在调用前报错。编号只用于查找文件，提示词改成视觉描述；无文字不等于无车窗带。
3. 接入两处后端：纹样素材按现有去背景链路；整车效果不去背景。仅本地开关开启、已登录用户可使用Codex。保留原供应商代码，不自动重试切换。
4. 前端明确显示实际发送的图片清单/数量及角色，保留现有生成操作；移除假结果阻断真实生成的分支仅在本任务相关范围内处理。
5. 回归：单图/多图顺序、案例说明、布局语义、丢图/超限、编号不进入绘制要求、Codex失败和返回图片；完整测试构建。真实多图实测一次，不宣称图像质量已保证。

实施分工：独立适配器委派，主代理负责设计包和两端集成。最后依次进行需求复核与质量复核，不提交或清理用户原有改动。
