## 验证与使用

在 gaotie-web 中运行 `npm run dev`，登录工作台，纹样检索得到结果后切换「Neo4j 原生」。如果已有开发服务，配置更新需要重启。保持本机 Neo4j 的 7474 和 7687 端口可用，在内嵌 Browser 登录并点击 Run。切换批次、检索分组或重新加载后需再次运行预填查询。

浏览器实测使用截图中的 P00364：代理资源加载成功，查询自动预填，Bolt 登录成功，返回 8 个节点和 7 条关系（母题、朝代、构图、材质和载体）。验证使用独立临时组件页面；完整工作台本次停在应用登录页，组件集成由 PatternGallery 测试覆盖。截图：output/neo4j-native/native-browser-verified.jpg。

此方案嵌入完整 Neo4j Browser，不是只抽取一张图，也不会复用原来 localhost:7474 页面的登录和图谱布局。Browser 自身决定凭据的会话行为，本系统新增代码不携带密码。它保留所登录账号的查询权限，本次生成的查询均为读取；不能视为受限只读设计师客户端。上线前需独立设计只读权限、受控代理和可访问的数据库地址，不能直接暴露开发服务。生产构建不加载 iframe，仅保留打开本机 Browser 的链接。
