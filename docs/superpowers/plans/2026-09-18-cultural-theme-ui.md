# 文化主题解读页视觉与交互

## 已确认设计

复用纹样检索页黑白灰、荧光黄绿、字体、边框、圆角及左右栏比例。文化主题与纹样页沿用同一侧栏；品牌留白，无进度条。AI 回复放入白色圆角边框卡片，用户消息灰底右对齐；标签按主题分组，以＋/✓切换。右侧已选意象仅显示主题、名称和移除按钮，不带装饰图标。

底部固定聊天输入，Enter 发送、Shift+Enter 换行、输入法确认不误发，等待回复期间防重复发送。“查找纹样”传递选择并切到检索。保留项目与历史会话，不改模型、提示词或检索规则。标签只来自返回的 TAG 标记或结构化 tags；React 文本渲染，不执行 HTML。
