# 纹样转化画布 Implementation Plan

**Goal:** 实现已确认的整屏画布与可拖动悬浮卡片，保留既有转化能力。

**Architecture:** 沿用 SuperCanvasPage 的图层、截取、生成及项目状态。新增 FloatingCanvasPanel 封装标题栏拖动、边界约束和折叠，独立浮层放置编辑器。仅修改前端，不增加撤销功能。

**Tech Stack:** React、TypeScript、现有 TDesign 图标、Vitest。

## 已确认规范

左侧保持系统导航；工作区是连续浅灰点阵画布。已选纹样、参考图为可折叠悬浮卡片，仅拖动标题栏移动，不触发图层操作。卡片不能拖出工作区，窗口缩小时重算边界。参考图无标题、时间或下一步按钮，保留图片、删除及添加回画布操作。图片导入只在底部长条工具栏；无撤销和重做按钮。右键菜单不标快捷键。保留裁剪、镜像、旋转、画笔、截取和 AI 转化。

## 后续微调：工具与生成反馈

用户确认：截取用虚线矩形，裁剪用交叉直角；移除数值参数编辑面板；镜像和复制仅在双击图片后的紧凑操作条中展示，保留右键快捷操作。工具悬停或键盘聚焦显示名称。底部输入改为宽版多行输入，Enter 发送、Shift+Enter 换行，输入法确认不误发。

生成接口在客户端请求 NDJSON 时发送真实阶段：准备参考图、优化提示词（仅实际有优化的链路）、生成图片、处理图片。兼容原 JSON 请求。不增加确认步骤；生成期间隐藏详情，成功后可展开原始需求与优化后的提示词。仅返回这两项文本和模式，不返回内部观察、系统提示或凭据。提示词记录附在生成图层上，随现有项目图层保存。无优化记录的链路不虚构详情。

先补失败测试，再实现接口读取、阶段与完成态。前端检查覆盖分片/中文流读取、连接中断、生成期间详情隐藏、生成成功详情折叠、镜像、复制、无数值参数；后端覆盖鉴权、校验、断连取消、JSON 兼容、错误脱敏及实际阶段顺序。

实际浏览器已检查双击镜像（再次点击还原）、工具提示、132px 高的宽版输入及数值参数移除。本轮不触发付费生图，完整生成反馈由模拟流与后端模拟生成器验证。
