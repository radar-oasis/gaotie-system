# 看图后转化：单方案试验

用户已确认：Codex 先观察实际参考图片，再基于原始意愿优化提示词，然后生成单个独立纹样；暂不生成四方案拼图。

1. 为本地 Codex 适配器添加可选的两阶段模式，第一轮只返回经过校验的观察与提示词，第二轮携带同一组参考图生图。整车生成保持原路径。
2. 优化规则：可见事实与推测分开；用户明确动作、风格、颜色优先；只补充必要的可执行视觉描述；保留辨识特征而非锁死全部轮廓；不主动添加颜色、装饰和多方案。
3. 保存原始输入、观察、优化提示词及工具修订提示词，便于回看；前端明确生成时自动看图优化。
4. 先添加并运行失败测试，再实现；运行回归、构建，再用现有龙纹做一次真实试验。失败不假称成功，不静默退回纯文本优化。

本轮不改旧的手动文字建议工具、不部署线上、不改变最终整车生成。
